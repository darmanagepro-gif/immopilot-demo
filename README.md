# ImmoPilot – démo publique

Démonstration interactive d'ImmoPilot (gestion immobilière, Marrakech) avec des **données entièrement fictives**.
Choisissez un profil en haut de la page : propriétaire, agence, gardien, ménage, artisan, locataire, voyageur…

- Location longue durée : appels de loyer, relances et quittances envoyés automatiquement en PDF (simulés), agent de rédaction du bail, des états des lieux et des courriers.
- Aucune donnée réelle, aucun e-mail ni paiement : tout est simulé dans la page.
- Rien n'est enregistré : recharger la page remet la démo à zéro.
